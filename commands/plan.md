# Plan

Read the project's instructions and inspect the affected code before proposing changes.
State the desired behavior, scope, dependencies, implementation steps and validation plan.
Identify genuinely missing decisions and resolve routine choices from the project context.
A request for a plan alone ends with the plan. If the user has already authorized implementation,
continue within that scope without repeatedly requesting the same approval.
Use additional agents only when authorized and useful for the task.
